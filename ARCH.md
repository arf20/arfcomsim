# Arquitecture

## Economy library

libecon

 - Database: product table, input-output tables
 - Economic solver
    - Labour (direct + indirect) cost (content) of production of each product.
      Iterative approximation. _Simplifying the labour value problem, Pg.49 Towards a New Socialism, Paul Cockshott_
    - Production quotas for each industry

All work-labour times are for a work week. For example, 1000 workers for a week
is represented as 1000 work-weeks.
